# Clock Island quality pass — 2026-11-09

## Verified

`node --test tests/regression.cjs`: 17 successful tests. The dependency-free VM harness runs the actual inline game code, stubs DOM/audio, and flushes timers deterministically.

- All 12 levels initialize, and each recorded path in `solutions.json` reaches the goal from a fresh state.
- Reset and rewind during rotation no longer allow the old animation callback to mutate the new/restored board (both reproduced failing before the fix).
- Progress persists and reloads; invalid JSON, non-integer unlock values and non-boolean clear flags are rejected/normalized.
- CSS board sizing now accounts for 7 cells, 6 gaps and body padding; phase text may wrap rather than overlap the board. Controls retain the original art and colors; labels, 44px targets, focus rings and reduced motion added.

## Important design finding

The solver found paths for every level **without placing blocks**. Level 4 clears with one gravity toggle and level 10 with one clockwise rotation. These are legal paths in the current implementation, not evidence of intended puzzle depth. Rotation, reverse gravity and afterimages are available before their introduction; hiding buttons alone would not resolve keyboard access. Mechanics were deliberately not changed in this patch. Next design experiment: explicitly define unlocked mechanics per level, then recheck intended solutions before changing progression.

## Not verified

Real iPhone/Android, 390×844 screenshot/visual QA, first-time understanding, full browser timing and audio. Installed Chromium failed with `socket() failed: Operation not permitted`; VM tests do not replace those checks. Game Off submission / AI declaration / itch publication remain unverified.
