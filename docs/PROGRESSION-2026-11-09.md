# 全12面の積み方と学習設計

## 変更の狙い

以前の12面には、箱を置かずに旗へ着く経路がありました。今回は「箱を置いた回数を満たせばクリア」のような条件を足さず、実際に足場が必要な地形と操作範囲に変更しています。既存のキャラクター、配色、効果音、時計島の設定は維持しています。

- 各島の回転は1回。残像を組み合わせる10面のみ2回。画面に残数を表示し、巻き戻すと使用回数も戻ります。
- 現象は島ごとに設定します。後の面で紹介する現象を先の面で使うことはできません。非表示のボタンだけでなく、共通関数がキーボード入力も制限します。
- 逆重力・無重力への切り替えは、回転後に着地してから行います。6・12面は下／上、9面は下／無重力の2択です。
- 箱は離れると消えます。4面の時間停止と、全編で使える巻き戻しは観察・試行の補助です。使用自体をクリア条件にしていません。
- 落下中の回転と先行入力は残しています。回転中の積み直しはできません。

## 面ごとの学習目的と意図解

列番号は左から **1〜7**。右・左は1マス移動を表し、通常は着地を待って操作します。機械再生用の0始まり座標と全操作列は `solutions.json` にあります。

| 面 | 学習目的 | 用意する箱 | 意図する流れ |
|---|---|---|---|
| 1 はじめての足場 | 積む高さが横向きの道の長さになる | 5列目に4個 | 右回転 → 右へ5歩。短い道だと床の穴へ落ちる |
| 2 逆向きの階段 | 左回転と固定の石を利用する | 5列目に3個 | 左回転 → 左へ5歩。石が次の着地点になる |
| 3 箱を分ける | 長い道と短い足場を配分する | 4列目に1個、5列目に4個 | 右回転 → 右へ5歩。短い足場で石を越え、長い道へ降りる |
| 4 試して、巻き戻す | 2段の着地点を読み、失敗から戻す | 3列目に1個、5列目に4個 | 右回転 → 右へ5歩。時間停止で落下を観察し、↩で置き方を試せる |
| 5 勢いで割る | 早送りとヒビ床 | 4列目に4個 | 右回転 → 右へ3歩 → ⚡ → 右。短い落下を加速して割る |
| 6 天井への道 | 足場を渡ってから逆重力 | 5列目に4個 | 右回転 → 右へ4歩 → 重力反転。石の下の旗へ上昇する |
| 7 はずむ足場 | 長い落下と直前の進行方向でバウンド | 3列目に4個 | 右回転 → 右へ4歩。道の端から落ちて高い旗へ跳ねる |
| 8 風の渡し場 | 落下中にずれる着地点を見越す | 5列目に5個 | 右回転 → 右へ2歩。風が石の先へ運び、長い足場で受ける |
| 9 浮遊の発射台 | 箱への安全な着地から無重力へ | 3列目に1個 | 右回転 → 右 → 無重力 → 左 → 下2歩 → 右2歩。柱の横を回り込む |
| 10 自分を足場に | 消える箱と画面に残る残像を組み合わせる | 5列目に4個 | 右回転 → 右 → 左 → 右回転 → 左 → 右。消した箱の空間と残像で旗へ戻る |
| 11 渦への階段 | 足場からワープに入る | 5列目に4個 | 右回転 → 右へ4歩。渦の出口が旗 |
| 12 時計島の帰り道 | 石・箱・ワープ・逆重力を順に組み合わせる | 3列目に3個 | 右回転 → 右へ4歩 → 重力反転。渦へ上昇して囲まれた部屋へ入り、同じ重力で旗へ昇る |

これらは確認済みの意図解で、唯一解や最短解の主張ではありません。特に4面は時間停止を必須にせず、観察・やり直しの練習面として設計しています。

## 自動検証

`node --test tests/regression.cjs` で以下を実行します。

1. 全12面の記録済み解法を、実際のゲーム関数で最初から再生する。
2. 箱なしで各面の着地状態から全有効操作を探索し、解なしで探索が閉じることを確認する。状態上限に達した場合は合格にしない。
3. 箱なしでタイマー1刻みと入力を入れ替える回帰探索を行う。落下中の回転、回転中の先行入力、早送りの切り替えも含む。
4. 5〜12面について、紹介する現象を除いた着地単位探索が解なしになることを確認する。12面はワープ・逆重力を個別に除去する。
5. 残数、ボタンとキーボードの制限、回転中の積み直し禁止、時間停止、巻き戻し、消えた箱・石・方向・早送りの復元、保存、最終面クリア直後のリセットを検証する。

`node tests/solve.cjs` は全合法な箱の配分から探索し、`solutions.json` を明示的に更新するための開発コマンドです。CIは期待値を勝手に更新しません。

### 検証範囲の限界

着地単位探索は回転・移動・対象島の重力・早送りを含む有限モデルです。タイマー割り込み探索も回帰用の状態モデルで、タイマーのクロージャ全体や巻き戻し履歴を完全に状態化していません。停止・巻き戻し・リセットは別の回帰テストで検証しています。実ブラウザーの全操作列に対する数学的な完全証明ではありません。

[追加ブラウザQAと独立レビュー](QA-PR2-BROWSER.md)で、新しい文言・地形の2サイズ表示、全12面のクリック操作、保存と旧セーブの継続を確認しました。実機のタッチ操作、Safari、音、初見の理解度・難易度曲線のユーザーテストは未確認です。従来版のスクリーンショットを新しい盤面の証拠として流用していません。

## 次の手動評価

- クラウドChromeで確認済みの390×844 / 320×640表示を、実機でも確認。
- 1〜4面を説明なしで遊び、「積む高さ→道の長さ」「箱が消える」「↩で戻れる」が伝わるか観察。
- 5〜12面で、必要な現象を自力で発見できるか、行き詰まりとヒントの不足を記録。
- 全面で回転中／落下中の連打、停止と再開、巻き戻し、タイトル、リロードを試す。
- 難しい箇所が地形の推理なのか操作タイミングなのかを区別して調整する。
